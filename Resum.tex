\chapter{Resumen}

[spa] Sports League consiste en un sistema de gestión de ligas deportivas. Permite a cualquier individuo que se registre: crear, organizar y gestionar ligas deportivas de diferentes deportes. La aplicación está pensada para que la gestión de una liga, durante todo su ciclo de vida, ocurra dentro de la aplicación. Algunas de las funcionalidades destacadas que incluye el sistema son: creación de ligas basada en la consecución de fases de distintos tipos, jerarquía de roles dentro de una liga, creación de equipos y solicitudes de unión a estos, asignación de fechas de partidos mediante acuerdos entre los capitanes de los equipos enfrentados, asignación automática de árbitros a partidos mediante algoritmos que equilibran el arbitraje, generación y resolución de incidencias y funcionalidades básicas que se pueden encontrar en cualquier aplicación de gestión de ligas deportivas.

La aplicación está pensada como un sistema multitenencia que sigue una arquitectura cliente-servidor y que permite la comunicación entre los usuarios y el sistema central. Sports League se ha diseñado e implementado como una aplicación full-stack que consta de: una API implementada en Spring Boot-Kotlin, que hace el papel de servidor back-end, conectada a una \ac{BD} PostgreSQL y un \ac{OS} MinIO, ambos locales; y una interfaz multiplataforma implementada con React Native, que permite la interacción de los usuarios con el sistema.

\chapter{Resum}
[cat] Sports League consisteix en un sistema de gestió de lligues esportives. Permet a qualsevol individu que es registri: crear, organitzar i gestionar lligues esportives de diferents esports. L'aplicació està pensada perquè la gestió d'una lliga, durant tot el cicle de vida, passi dins l'aplicació. Algunes de les funcionalitats destacades que inclou el sistema són: creació de lligues basada en la consecució de fases de diferents tipus, jerarquia de rols dins d'una lliga, creació d'equips i sol·licituds d'unió a aquests, assignació de dates de partits mitjançant acords entre els capitans dels equips enfrontats, assignació automàtica d'àrbitres a partits mitjançant algorismes que equilibren l'arbitratge, generació i resolució d'incidències i funcionalitats bàsiques que es poden trobar a qualsevol aplicació de gestió de lligues esportives.

L'aplicació està pensada com un sistema multitinença que segueix una arquitectura client-servidor i que permet la comunicació entre els usuaris i el sistema central. Sports League s'ha dissenyat i implementat com una aplicació full-stack que consta de: una API implementada a Spring Boot-Kotlin, que fa el paper de servidor back-end, connectada a una \ac{BD} PostgreSQL i un \ac{OS} MinIO, tots dos locals; i una interfície multiplataforma implementada amb React Native, que permet la interacció dels usuaris amb el sistema.
